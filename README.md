One line of wedding vows for a robot couple — the funniest single line, judged pairwise by a deadpan officiant model.

> "I take you to be my lawfully wedded co-processor, to have and to hold, in sickness and in low battery, till a factory reset do us part."

## Run it

```sh
node main.ts
```

Writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The program validates the sealed gate itself before writing: UTF-8 text, 1–160 characters, not only whitespace, exactly one line.
